# CyberTalents CTF Writeups

A collection of hands-on **Capture The Flag (CTF)** challenge writeups, documenting my approach to investigating problems, testing hypotheses, using security tools, and validating results.

The goal is to share reproducible methods and lessons learned—not just flags.

## Challenge categories

| Category | Challenges | Focus |
| --- | --- | --- |
| 🔎 [Digital Forensics](DigitalForensics/) | [Err](DigitalForensics/Err/) · [Duck](DigitalForensics/Duck/) | File analysis, evidence collection, and artifact investigation |
| 🔐 [Cryptography](cryptographique/) | [Crack the Hash](cryptographique/Crack-the-Hash/) | Hash identification, password-recovery techniques, and verification |

> Some challenge directories are works in progress. Each completed writeup includes the problem, tools used, a step-by-step approach, and supporting evidence where available.

## How to use this repository

Open a challenge folder, then read its `README.md` for the investigation process. Commands are included for educational use in authorized CTF environments. Screenshots illustrate relevant steps, errors, and verification results.

## Disclaimer

All techniques described here are for educational purposes and authorized cybersecurity challenges only.
